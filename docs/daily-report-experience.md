# Phase 9.2 — Daily research reading flow

Executive Summary → What Changed → Why It Matters → Market Structure → Risks
Ahead → Evidence Trail. The existing brief, priorities, regime, signals, shadow
and audit panels remain. Existing top-story order, why/monitor text and evidence
references are reused, never generated or re-ranked by the page.

What Changed compares observable market snapshot prices and recorded statuses
only, not inferred market causes or derived event importance. Both values,
source and observation timestamps remain visible. Stale is explicitly labeled
as recorded status. The comparison does not claim live freshness, and does not
compute predictions or trading recommendations. Missing/nonchronological/
incompatible observations are omitted with a clear unavailable/no-comparable
message. It is not a full diff of all intelligence objects.

Pages workflow discovers the previous successful default-branch run with an
unexpired daily-report artifact. Only its market_snapshot.json is projected
into the restricted `previous-market-snapshot.json` presentation artifact.
No historical artifact becomes an AI/intelligence input. Missing/invalid prior
snapshot leaves comparison unavailable. Other historical files are not published.
Publication allowlist adds only this single projection, validated again before
deployment. Existing producer contracts stay unchanged.

Equity/Macro/Crypto labels group existing market cards; shadow remains separately
labeled and production-disabled. Risks use existing categories and warnings.
Evidence IDs remain text nodes, unchanged and accessible in disclosure groups.
The existing responsive single-column breakpoint and wrapping reference IDs
support mobile; no fixed-width comparison table is added.

No local historical run is invented for this review. The local page correctly
shows previous-run missing until an actual retained prior artifact is supplied.
No commit/deployment or remote workflow execution in this phase.
